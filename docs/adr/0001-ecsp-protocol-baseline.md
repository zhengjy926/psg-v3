# 沿用 ECSP V0.2 作为 v3 协议基线

v3 重写固件，但现场上位机已按《脉冲信号发生板接口协议规范》V0.2（ECSP）部署。决定：帧格式、命令集 `0x01–0x43`、应答码、参数范围冻结沿用；v3 的语义改动集中列在《需求规格说明书》的协议差异附录，新增命令只从 `0x44` 起。

理由：现场已部署上位机，重定义协议会让重写固件的收益被联调成本吃掉。把「沿用」与「沿用但语义变了」分开记，是为了避免「字节冻结」掩盖行为变化——例如 `0x36` 载荷由 7 字节缩为 6 字节、通道状态不再出现 `0x05`，都是冻结了帧结构却改变了行为。

**代价**：每个命令的兼容性必须逐条评估，不能靠「帧结构没变」推断整机兼容。
