## 2. 范围与边界

| 项 | 结论 |
| --- | --- |
| 覆盖 | 本板固件：启停、触发、出波、杆控制、电流采样与结算、异常判定、协议从机、自检、状态指示 |
| 不覆盖 | 上位机软件；回路阻抗采集与端口控制板（板卡地址 0x03）与贴靠阻抗采集板（板卡地址 0x05）自身的行为；产线工装；硬件设计；软件分层与模块划分 |
| 业务口 | USART2（PA2/PA3），跑 ECSP 帧 |
| 单板调试版协议口 | USART1（PC4/PC5），被编译期宏选中时即唯一协议口（同一命令集、同一地址过滤、上报齐全） |
| 协议口选择 | 由编译期宏二选一：发布版用 USART2，单板调试版用 USART1；运行期不抢占、不切换 |
| 日志 | Zephyr logging 框架 + RTT 后端，不占业务串口（见 N-006） |
| 工具链 | Keil MDK-ARM V5.32 + armclang(AC6) |
| 寻址 | 产品地址 0x03 + 板卡地址 0x02；非本板地址的帧丢弃且不应答 |
| 本板角色 | 链路上的寻址从机，不为 0x03/0x05 转发或中继任何报文 |

## 3. 功能需求

### 3.1 启停与触发

| 编号 | 需求 | 依据 | 验收 |
| --- | --- | --- | --- |
| F-001 | 启停输入源由 0x3E 配置：0 = 协议、1 = 端口；上电默认为协议。 | 协议 0x3E | PC |
| F-002 | 同一时刻只有一个启停输入源有权作出受理启动与中途停止，即 0x3E 的当前取值。 | 术语「启停输入源」 | PC |
| F-003 | 受理启动的来源：启停输入源为协议时是 0x30 控制码 1；为端口时是端口启停输入（PB4）的正向过渡。 | 术语「受理启动」「协议启动」「端口启动」 | PC / OSC |
| F-004 | 不受理启动的情形：非空闲、故障字 bit1 置位、任一通道过流检出（过流阈值被越过）、电流异常未清除、电压阈值、电流阈值未配置（为 0）或序列参数未设置。前置条件不满足回 0x13；运行中回 0x11；故障态回 0x15；参数非法回 0x03；不支持的命令回 0x04；启停输入源为端口时收到 0x30 启/停回 0x12（模式异常）。 | 术语「受理启动」「过流检出」 | PC |
| F-005 | 直接触发：受理启动后不等待 R 波，立即开始一次序列输出；一次运行只做一次序列输出。 | 术语「直接触发」 | OSC |
| F-006 | 边沿触发：受理启动后先等待 R 波，每次 R 波正向过渡开始一轮。 | 术语「边沿触发」「轮」 | OSC |
| F-007 | 边沿触发参数：触发延迟 0–300 ms、触发间歇 200–2000 ms、触发次数 1–300。 | 协议 0x36，本版修订 | PC |
| F-008 | 触发延迟自每轮 R 波正向过渡起算，到该轮第一个脉冲间隔开始；时长为 0 时立即开始该脉冲间隔。 | 术语「触发延迟」 | OSC |
| F-009 | 触发间歇只出现在非末轮序列输出完成之后、下一轮等待 R 波之前。 | 术语「触发间歇」 | OSC |
| F-010 | 触发间歇期间的 R 波一律忽略，不计入触发次数、不补触发。 | 术语「触发间歇」「触发次数」 | OSC |
| F-011 | 运行完成：直接触发下那一次序列输出完成；边沿触发下触发次数所要求的轮全部完成。此后回到空闲。 | 术语「运行完成」 | PC |
| F-012 | 中途停止：启停输入源为协议时是 0x30 控制码 0；为端口时是端口启停输入（PB4）的负向过渡。停止立即结束运行并回到空闲，不计入已完成触发次数。 | 术语「中途停止」 | PC / OSC |
| F-013 | 启停输入源与触发方式正交，四种组合（协议/端口 × 直接/边沿）都必须可用。 | 术语「触发方式」 | PC |
| F-014 | 运行指示（PB5）在运行中为高电平、不在运行中为低电平。 | 引脚表 | 万用表 |
| F-015 | 板载 LED（PB9）低有效，上电后以 1 Hz 周期翻转；不承载故障语义。 | 引脚表 | 目视 |
| F-016 | 运行中修改启停输入源、触发方式、序列参数、触发参数或杆选通应被拒绝并回 0x11，配置保持不变；空闲且无电流异常时受理。 | 安全需要 | PC |

| F-023 | 序列内各脉冲群可以不同；同一脉冲群内各脉冲串相同、各重复单元相同。 | 术语「脉冲群」「脉冲串」 | OSC |
| F-024 | 脉冲持续时间按配置电压选标定档位换算为实际输出时长；电压取 1500/2000/2500/3000/3500/4000 V 中最近档。 | 术语「标定」、v2 标定表 | OSC |

| F-026 | 标定数据随固件版本发布，并可由 0x44 写入、0x45 读回；一帧写一个电压档位，整档校验通过后原子提交，失败保留旧表。仅空闲受理（运行中回 0x11、故障态回 0x15），受理启动时冻结运行计划。 | 协议 0x44（本版新增） | PC |

### 3.3 杆与杆选通

| 编号 | 需求 | 依据 | 验收 |
| --- | --- | --- | --- |
| F-027 | 六杆映射：PD13=A、PD12=B、PD11=C、PD10=D、PD9=E、PD8=F，高电平为杆导通；杆对位图 bit0=A…bit5=F。 | 引脚表 | 万用表 |
| F-028 | 空闲且无电流异常时的杆状态：杆对循环未使能时按杆选通驱动（上电默认六杆全通）；杆对循环已使能时只让 AB 这一对杆导通。电流异常或故障时六杆全断。 | 术语「杆选通」「六杆全通」「六杆全断」 | 万用表 |
| F-029 | 杆对循环由 0x40 使能：每个脉冲串只让一对杆导通，顺序为 AB→CD→EF→BC→FA→DE，按脉冲串序号取模循环。使能时每群脉冲串数必须是 6 的倍数，否则回 0x03。 | 术语「杆对循环」 | OSC / 万用表 |
| F-030 | 杆对循环未使能时，运行期间每个脉冲串按杆选通（六杆全通或某一对杆）驱动。 | 术语「杆选通」 | 万用表 |
| F-031 | 杆由关断驱动到导通后，须保证自驱动起经过的时间 ≥ MOSFET 导通延迟时间（固定 1 µs、编译期 `#define` 常量）才开始该脉冲串出波，自然已满足则不再额外插等待；该窗口内到达的 R 波无效。杆关断不额外插入等待。 | 术语「MOSFET导通延迟时间」、研究报告 CI58N330SM4 | OSC |
| F-032 | 杆对切换与杆选通切换只发生在脉冲串间隔内，不得在脉冲窗口（脉冲持续时间 + 极性间间隔）内切换。 | 安全需要 | OSC |
| F-033 | 杆选通由 0x42 设置，取值为六杆全通或六个杆对之一（AB、CD、EF、BC、FA、DE）；只能在空闲且无电流异常时设置，设置成功后立即生效，上电默认六杆全通。 | 评审裁决、术语「杆选通」 | 万用表 |
| F-034 | 运行中或故障态设置杆选通回 0x11 或 0x15，配置保持不变。 | 安全需要 | PC |

| F-043 | 序列输出平均电流为一次序列输出中该通道全部已得采样的算术平均，只用于上报、不在序列级做欠流判定（判欠流在每群结算上做）；该通道没有采样数据时该路没有这个平均，0x31/0x3C 以 0.0 表示。 | 术语「序列输出平均电流」「结算」 | PC |
| F-044 | 已完成触发次数只统计已完成的轮，未完成的轮不计。 | 术语「已完成触发次数」 | PC |

## 6. 异常与安全需求

| 编号 | 需求 | 依据 | 验收 |
| --- | --- | --- | --- |
| E-001 | 过流异常有两条成立路径：过流检出（比较器，阈值由 0x38 配置）与过流锁存（独立硬件，固定 90 A，不受软件与 0x38 影响）；运行中任一成立即立刻停止出波、六杆全断、本群不再等齐样也不再做欠流判定，并记录电流异常。 | 术语「过流异常」「过流锁存」 | OSC / PC |
| E-002 | 没有运行时过流不记录、不锁存；但受理启动时若过流检出仍成立或过流锁存仍成立，则不受理这次启动。 | 术语「过流异常」 | PC |
| E-003 | 故障字 bit1 = 过流锁存硬件故障：置位时不受理启动；0x3D 清除电流异常时同时做过流锁存复位，bit1 随之消失。 | 术语「故障字」 | PC |
| E-004 | 电流异常记录只能由 0x3D 清除；清除后回空闲，不得自动恢复出波。 | 术语「电流异常」 | PC |
| E-005 | 过流异常造成的停波后保持六杆全断，直到 0x3D 清除并回到空闲；运行完成与中途停止造成的停波后立即按 F-028 的空闲杆状态驱动。 | 安全需要 | 万用表 |
| E-006 | 上电初始化完成前不得输出脉冲、不得有杆导通；六杆依赖外部下拉保持关断。 | 安全需要 | OSC |
| E-007 | 参数校验失败（0x03）不改变既有配置；非易失写入失败不改变运行配置与标定表。 | 安全需要 | PC |
| E-008 | 独立看门狗约 1 s 超时；只有正常调度路径喂狗，任一活动对象阻塞超时即复位。 | v2 配置 | 调试器 |
| E-009 | 复位后运行参数全部恢复默认；非易失只保存软件版本、硬件版本、SN 与标定表。 | 评审裁决 | PC |
| E-010 | 自检失败置故障字 bit0，其后一次自检成功清除；bit0 不阻止受理启动。 | 评审裁决 | PC |
| E-011 | 标定区采用 A/B 双区交替，含版本号与 CRC；写入完整并校验通过后才切换有效区标志，写入中断电回退旧区。 | 评审裁决 | 台架掉电 |
| E-012 | 过流锁存是与过流检出完全独立的硬件通路，正、负通道均为固定 90 A，不可配置、不可屏蔽；它是防止软件与比较器失效的最后一道防线，任何配置或状态都不得削弱它。 | 术语「过流锁存」 | 台架过流 |
